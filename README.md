# JAP — Apuração Eleições 2026

Aplicação Streamlit configurável para acompanhamento dos resultados oficiais do TSE.

## Produto público
O usuário informa nome, UF, cargo e número e pode acompanhar até quatro candidatos simultaneamente.
O painel também apresenta Presidente, Governador e Senado da UF selecionada.

A interface pública não exibe classificação de atuação da JAP.

## Executar
```bash
pip install -r requirements.txt
streamlit run app.py
```
